# Private Management

The private dashboard is for approved JunctionNow operators.

It can:

- sync the feed now
- pause or resume the feed
- view installed servers
- create a one-use access link when allowed
- turn photo requests on or off for an article

Private responses say **Only you can see this**.

The management server also has two private channels:

- `jn-photo-submissions`
- `jn-service-log`

The service log is intentionally small. It records only useful events such as
server installs, removals, feed errors, and management changes.
